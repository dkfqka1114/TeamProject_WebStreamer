# 시스템 프로그래밍 팀 프로젝트 - Web Streamer
## 프로젝트 개요
c언어로 구현된 웹 기반 스트리밍 시스템입니다.


## 팀 소개
### 이현동
발표, 회원가입/로그인 기능 구현

### 김현빈
스트리밍/채팅 기능 구현, UI 구현


## 기능 상세
### 1. 회원 가입/로그인
### 2. 스트리밍 송출/시청
### 3. 실시간 채팅


## 사용 기술
### 1. 파일 입출력
### 2. 소켓 프로그래밍
### 3. 멀티 스레드


## 빌드 및 실행
### 0. 빌드 준비
```
sudo apt update

sudo apt install build-essential
```

### 1. 빌드
```
make
```

### 2. 서버 실행
```
./server
```

### 3. 서버 접속
웹브라우저에서 localhost:8080으로 접속

### 4. 빌드 파일 정리
```
make clean
```

#### 주의 사항
localhost가 아닌 외부에서 접속할시 기본적으론 HTTPS 환경이 아니기 때문에 보안상의 문제로 화면 캡처가 작동하지 않습니다.
외부에서 원활하게 접속하기 위해선 서버의 8080 포트를 개방하고, 클라이언트 브라우저 보안 설정을 꺼야합니다.
